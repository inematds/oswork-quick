1. Tu computadora

Abre la terminal

cd

Crea la carpeta proyectos y la del primer proyecto

cd %USERPROFILE%
mkdir proyectos
cd proyectos
mkdir mi-sitio
cd mi-sitio

Mira en Windows dónde está todo

explorer .

Navega con 6 comandos

cd ..
dir
cd mi-sitio
dir

Instala Git, GitHub CLI y Node (una vez)

winget install --id Git.Git -e
winget install --id GitHub.cli -e
winget install --id OpenJS.NodeJS.LTS -e

Instala el agente: Claude Code o Codex

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
npm install -g @openai/codex

Trabaja dentro de la carpeta del proyecto

cd %USERPROFILE%\proyectos\mi-sitio
claude
dir
start index.html

2. GitHub

Dile a Git quién eres

git config --global user.name "Tu Nombre"
git config --global user.email "tu@correo.com"
git config --global --list

Crea tu clave SSH

ssh-keygen -t ed25519 -C "tu@correo.com"
explorer %USERPROFILE%\.ssh

Conecta gh a tu cuenta y envía la clave

gh auth login
ssh -T git@github.com

Crea el repositorio y envía el proyecto

cd %USERPROFILE%\proyectos\mi-sitio
git init
git add .
git commit -m "primera versión"
git branch -M main
gh repo create mi-sitio --public --source=. --push

Publica la página en GitHub Pages

gh api repos/{owner}/{repo}/pages -X POST -f "source[branch]=main" -f "source[path]=/"

La rutina de todos los días

git status
git add .
git commit -m "qué cambió"
git push

3. VPS

Contrata la VPS con tu clave

type %USERPROFILE%\.ssh\id_ed25519.pub

Conéctate a la VPS

ssh root@IP-DE-LA-VPS

La misma navegación, con otros nombres

mkdir -p ~/proyectos
cd ~/proyectos
ls
pwd

Lleva el proyecto de GitHub

apt update && apt install -y git
cd ~/proyectos
git clone https://github.com/TU-USUARIO/mi-sitio.git
cd mi-sitio
ls

Instala el agente en la VPS

curl -fsSL https://claude.ai/install.sh | bash
cd ~/proyectos/mi-sitio
claude

Trae los cambios y desconéctate

cd ~/proyectos/mi-sitio
git pull
ls
exit
