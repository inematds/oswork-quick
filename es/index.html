INEMA · OSWORK QUICK / EN LA PRÁCTICA

De la terminal a tu página en línea, comando por comando.

Abre la terminal de Windows, crea tu carpeta de proyectos, descubre dónde está todo, instala Claude Code o Codex, guarda el proyecto en GitHub con una clave SSH y llévalo a una VPS. Quien aprende a navegar en Windows navega en la VPS de la misma manera.

AL FINAL TENDRÁS

Un proyecto propio, guardado y publicado.

  • La carpeta C:\Users\TuNombre\proyectos\mi-sitio, que sabes encontrar desde la terminal y el Explorador de archivos.
  • Claude Code o Codex trabajando dentro de esa carpeta.
  • El proyecto en GitHub, con una clave SSH, y una página en TU-USUARIO.github.io.
  • El mismo proyecto en una VPS, usando los mismos comandos de navegación.

Los comandos provienen de la documentación oficial (Claude Code, Codex, GitHub CLI), verificada el 07/10/2026. Las pantallas y las versiones pueden cambiar: si algo aparece distinto, lee el mensaje con calma antes de repetir el comando.
