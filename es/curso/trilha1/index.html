MÓDULO 1.1

Terminal, carpetas y agente en Windows

Crear la carpeta proyectos\mi-sitio desde cmd, ver la misma carpeta en el Explorador de archivos y hacer que Claude Code o Codex trabajen en ella.

0%0 de 0

Qué es

Presiona la tecla Windows, escribe cmd y presiona Enter. Se abre una ventana negra: el Símbolo del sistema. El comando cd por sí solo muestra en qué carpeta estás.

Por qué aprender

Todo en este curso empieza aquí. La terminal es simplemente otra ventana para las mismas carpetas que ya ves en Windows.

Conceptos clave

Terminal: ventana donde escribes comandos en vez de hacer clic. cmd: la terminal clásica de Windows. Carpeta personal: C:\Users\TuNombre, donde están Documentos, Descargas y ahora tus proyectos.

Qué es

Escribe un comando a la vez y presiona Enter después de cada uno. mkdir crea la carpeta; cd entra en ella.

Por qué aprender

Una carpeta por proyecto es la regla que organiza todo lo demás: el agente, Git y la VPS siempre trabajan dentro de ella.

Conceptos clave

%USERPROFILE%: acceso directo a tu carpeta personal; funciona en cualquier computadora. mkdir (make directory): crea una carpeta. cd (change directory): entra en una carpeta.

Qué es

explorer abre el Explorador de archivos; el punto significa “la carpeta donde estoy”. Es el paso más importante del curso.

Por qué aprender

Cuando ves las dos ventanas mostrando el mismo lugar, la terminal deja de ser un misterio: lo que creas en una aparece en la otra.

Conceptos clave

Explorador de archivos: la ventana de carpetas de Windows. Punto (.): la carpeta actual. Dos puntos (..): la carpeta superior.

Qué es

Seis comandos bastan para moverte por las carpetas: dir muestra una lista, cd nombre entra, cd .. sube una carpeta, mkdir nombre crea una carpeta, explorer . la abre en Windows y cls limpia la pantalla.

Por qué aprender

Con estos seis nunca te pierdes, y en la VPS usarás los mismos con otros nombres.

Conceptos clave

dir: muestra una lista de archivos y carpetas. cd ..: sube una carpeta. cls: limpia la pantalla sin borrar nada. Tecla Tab: completa el nombre de carpetas y archivos mientras escribes.

Qué es

winget es el instalador de programas que ya viene en Windows 10 y 11. Descarga cada programa de la fuente oficial.

Por qué aprender

Git guarda versiones, gh se comunica con GitHub y Node es necesario para instalar Codex. Sin ellos, las partes 2 y 3 no funcionan.

Conceptos clave

winget: instalador de Windows por línea de comandos. Git: programa que guarda el historial del proyecto. gh (GitHub CLI): GitHub dentro de la terminal. Node: motor que ejecuta programas en JavaScript, como Codex.

Qué es

Elige uno o los dos. La primera vez que lo abras, el agente te pedirá que inicies sesión: usa tu suscripción (Claude Pro o Max, ChatGPT Plus o Pro).

Por qué aprender

El agente trabaja por ti dentro de la carpeta: lee, crea y modifica archivos con tu autorización.

Conceptos clave

Agente: una IA que ejecuta tareas en tu computadora, no solo conversa. Claude Code: el agente de Anthropic. Codex: el agente de OpenAI. Suscripción: el inicio de sesión de tu cuenta, sin clave de API.

Qué es

Entra en la carpeta y ejecuta el agente (claude o codex). Solo puede ver la carpeta donde estás. AGENTS.md guarda las reglas del proyecto para las próximas conversaciones.

Por qué aprender

Aquí se completa el ciclo: haces la solicitud, el agente crea los archivos y tú lo compruebas con dir, el Explorador de archivos y el navegador.

Conceptos clave

index.html: la página principal de un sitio web. AGENTS.md: archivo de instrucciones que el agente lee al abrir la carpeta. start: abre un archivo con el programa predeterminado de Windows.
