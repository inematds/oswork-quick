MÓDULO 3.1

VPS: lo mismo, en un servidor

Conectarte a una VPS con Ubuntu usando tu clave, navegar con los mismos comandos y llevar el proyecto de GitHub allí.

0%0 de 0

Qué es

Elige un proveedor y el sistema Ubuntu. Al crear la VPS, te pedirá una clave SSH: pega la línea que muestra este comando. Anota la IP que te indique el proveedor.

Por qué aprender

Con la clave registrada, puedes entrar sin contraseña y nadie sin tu clave privada podrá entrar.

Conceptos clave

VPS: una computadora Linux alquilada que está encendida las 24 horas. Ubuntu: la versión de Linux más usada en servidores. IP: la dirección numérica del servidor. type: muestra el contenido de un archivo en cmd.

Qué es

Reemplaza IP-DE-LA-VPS por el número que te dio el proveedor. La primera vez te preguntará si confías en el servidor: responde yes. Para salir, escribe exit.

Por qué aprender

Es la misma ventana de siempre, pero conectada a otra computadora. Todo lo que escribas ahora ocurre en la VPS.

Conceptos clave

ssh: abre una conexión segura con otra computadora. root: el administrador de Linux. ~: la carpeta personal del usuario en la VPS. exit: cierra la conexión y vuelve a Windows.

Qué es

En la VPS: dir se convierte en ls, cls en clear, type en cat, %USERPROFILE% en ~ y la barra es / en vez de \. cd, cd .. y mkdir son iguales. No hay Explorador de archivos: ls cumple esa función.

Por qué aprender

Por eso el curso empieza en Windows: quien entiende las carpetas allí puede navegar en la VPS en minutos.

Conceptos clave

ls: muestra la lista de la carpeta. pwd: muestra dónde estás. mkdir -p: crea la carpeta y no da error si ya existe. Linux distingue entre mayúsculas y minúsculas: Proyectos y proyectos son carpetas diferentes.

Qué es

apt instala Git en Ubuntu. git clone copia todo el repositorio, incluido el historial, a la carpeta actual.

Por qué aprender

GitHub es el puente: el mismo proyecto está en Windows y en la VPS, y las versiones pasan de un lado al otro.

Conceptos clave

apt: el instalador de Ubuntu (parecido a winget). git clone: descarga un repositorio por primera vez. && : ejecuta el segundo comando solo si el primero salió bien.

Qué es

El comando de instalación para Linux es el de la documentación oficial. La primera vez, el agente muestra una dirección: ábrela en el navegador de tu computadora e inicia sesión con tu suscripción.

Por qué aprender

Con el agente en la VPS, el trabajo puede continuar en el servidor aunque tu computadora esté apagada.

Conceptos clave

install.sh: el instalador para Linux y Mac. | bash: entrega el instalador descargado a la terminal para que lo ejecute. Inicio de sesión sin pantalla: el agente muestra un enlace y un código para que autorices desde otro dispositivo.

Qué es

¿Cambiaste algo en Windows e hiciste push? En la VPS, git pull trae el cambio. Para volver a Windows, escribe exit.

Por qué aprender

Es la rutina entre las dos computadoras: push de un lado, pull del otro, siempre a través de GitHub.

Conceptos clave

git pull: trae las versiones nuevas de GitHub. exit: cierra la conexión SSH. Para volver: ssh root@IP-DE-LA-VPS y cd ~/proyectos/mi-sitio.
