MÓDULO 2.1

Git, gh y clave SSH en GitHub

Conectar tu computadora a tu cuenta de GitHub con una clave SSH, crear el repositorio (público o privado) y publicar la página.

0%0 de 0

Qué es

Usa el mismo correo electrónico de tu cuenta de GitHub. Se hace una vez por computadora.

Por qué aprender

Cada versión guardada lleva tu nombre. GitHub usa el correo electrónico para vincular las versiones con tu cuenta.

Conceptos clave

git config: configura Git. --global: se aplica a todos los proyectos de esta computadora. Commit: una versión guardada del proyecto, con autor y mensaje.

Qué es

Presiona Enter en las 3 preguntas para aceptar la ubicación predeterminada y continuar sin contraseña adicional. Después, el Explorador de archivos abre la carpeta donde quedaron las claves.

Por qué aprender

La clave SSH es tu identidad sin contraseña: GitHub y la VPS reconocen tu computadora por ella.

Conceptos clave

SSH: forma segura de conectar dos computadoras. Clave privada: se queda solo en tu máquina, nunca se envía. Clave pública (.pub): es la que entregas a GitHub y a la VPS.

Qué es

Responde: GitHub.com → SSH → elige id_ed25519.pub → Login with a web browser. Copia el código, pégalo en el navegador y autoriza. Después prueba la clave; la primera vez responde yes.

Por qué aprender

Un comando inicia sesión y envía tu clave pública a la cuenta, sin abrir la configuración del sitio.

Conceptos clave

gh auth login: inicia sesión en tu cuenta de GitHub desde la terminal. Protocolo SSH: Git empieza a usar tu clave en vez de una contraseña. ssh -T: prueba la conexión sin abrir nada.

Qué es

git init activa Git en la carpeta, add y commit guardan la primera versión, y gh crea el repositorio y envía todo. Para que sea privado, cambia --public por --private.

Por qué aprender

Público: cualquier persona puede verlo (necesario para Pages gratis). Privado: solo tú y las personas que invites. Tú decides en cada proyecto.

Conceptos clave

Repositorio: la carpeta del proyecto con todo el historial, guardada en GitHub. Branch main: la línea principal de versiones. Push: enviar las versiones a GitHub.

Qué es

Este comando activa GitHub Pages en el repositorio de la carpeta actual. También puedes hacerlo desde el sitio: Settings → Pages → branch main → Save.

Por qué aprender

Obtienes un enlace público a la página que creó el agente, sin pagar por el alojamiento.

Conceptos clave

GitHub Pages: alojamiento gratis de páginas a partir de un repositorio. {owner} y {repo}: gh los reemplaza automáticamente por tu usuario y el nombre del repositorio.

Qué es

¿Cambiaste algo? Revisa qué cambió, guarda una versión con una frase y envíala. O pídele al agente: guarda y envía a GitHub.

Por qué aprender

Cada commit es un punto de regreso. Si algo se rompe, puedes recuperar la versión anterior.

Conceptos clave

git status: muestra qué cambió desde la última versión. Mensaje del commit: una frase que dice qué cambió, para que puedas encontrarlo después.
