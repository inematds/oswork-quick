1. Your computer

Open the terminal

cd

Create the projects folder and your first project folder

cd %USERPROFILE%
mkdir projects
cd projects
mkdir my-site
cd my-site

See where everything is in Windows

explorer .

Navigate with 6 commands

cd ..
dir
cd my-site
dir

Install Git, GitHub CLI, and Node (once)

winget install --id Git.Git -e
winget install --id GitHub.cli -e
winget install --id OpenJS.NodeJS.LTS -e

Install the agent: Claude Code or Codex

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
npm install -g @openai/codex

Work inside the project folder

cd %USERPROFILE%\projects\my-site
claude
dir
start index.html

2. GitHub

Tell Git who you are

git config --global user.name "Your Name"
git config --global user.email "you@email.com"
git config --global --list

Create your SSH key

ssh-keygen -t ed25519 -C "you@email.com"
explorer %USERPROFILE%\.ssh

Connect gh to your account and send the key

gh auth login
ssh -T git@github.com

Create the repository and upload the project

cd %USERPROFILE%\projects\my-site
git init
git add .
git commit -m "first version"
git branch -M main
gh repo create my-site --public --source=. --push

Publish the page on GitHub Pages

gh api repos/{owner}/{repo}/pages -X POST -f "source[branch]=main" -f "source[path]=/"

Your daily routine

git status
git add .
git commit -m "what changed"
git push

3. VPS

Get a VPS with your key

type %USERPROFILE%\.ssh\id_ed25519.pub

Connect to the VPS

ssh root@VPS-IP

Same navigation, different names

mkdir -p ~/projects
cd ~/projects
ls
pwd

Bring your project from GitHub

apt update && apt install -y git
cd ~/projects
git clone https://github.com/YOUR-USER/my-site.git
cd my-site
ls

Install the agent on the VPS

curl -fsSL https://claude.ai/install.sh | bash
cd ~/projects/my-site
claude

Get the changes and disconnect

cd ~/projects/my-site
git pull
ls
exit
