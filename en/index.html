INEMA · OSWORK QUICK / HANDS-ON

From the terminal to your live page, one command at a time.

Open the Windows terminal, create your projects folder, see where everything lives, install Claude Code or Codex, save your work on GitHub with an SSH key, and move the project to a VPS. If you learn to navigate Windows, you can navigate a VPS the same way.

BY THE END, YOU’LL HAVE

Your own project, saved and published.

  • The C:\Users\YourName\projects\my-site folder, which you can find in the terminal and File Explorer.
  • Claude Code or Codex working inside that folder.
  • The project on GitHub with an SSH key, and a page at YOUR-USER.github.io.
  • The same project on a VPS, navigated with the same commands.
