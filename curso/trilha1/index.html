MÓDULO 1.1

Terminal, pastas e agente no Windows

Criar a pasta projetos\meu-site pelo cmd, ver a mesma pasta no Explorador e pôr o Claude Code ou o Codex para trabalhar nela.

0%0 de 0

O que é

Aperte a tecla Windows, digite cmd e aperte Enter. Abre uma janela preta: o Prompt de Comando. O cd sozinho mostra em que pasta você está.

Por que aprender

Tudo neste curso começa aqui. O terminal é só outra janela para as mesmas pastas que você já vê no Windows.

Conceitos-chave

Terminal: janela onde você escreve comandos em vez de clicar. cmd: o terminal clássico do Windows. Pasta pessoal: C:\Users\SeuNome, onde ficam Documentos, Downloads e agora os seus projetos.

O que é

Digite um comando por vez e aperte Enter depois de cada um. mkdir cria a pasta; cd entra nela.

Por que aprender

Uma pasta por projeto é a regra que organiza todo o resto: o agente, o Git e a VPS trabalham sempre dentro dela.

Conceitos-chave

%USERPROFILE%: atalho para a sua pasta pessoal, vale em qualquer computador. mkdir (make directory): cria uma pasta. cd (change directory): entra numa pasta.

O que é

explorer abre o Explorador de Arquivos; o ponto quer dizer “a pasta onde eu estou”. É o passo mais importante do curso.

Por que aprender

Quando você vê as duas janelas mostrando o mesmo lugar, o terminal deixa de ser mistério: o que você cria num aparece no outro.

Conceitos-chave

Explorador de Arquivos: a janela de pastas do Windows. Ponto (.): a pasta atual. Dois pontos (..): a pasta de cima.

O que é

Seis comandos bastam para andar pelas pastas: dir lista, cd nome entra, cd .. volta uma pasta, mkdir nome cria, explorer . abre no Windows e cls limpa a tela.

Por que aprender

Com esses seis você nunca se perde, e na VPS vai usar os mesmos com outros nomes.

Conceitos-chave

dir: lista arquivos e pastas. cd ..: sobe uma pasta. cls: limpa a tela sem apagar nada. Tecla Tab: completa o nome de pastas e arquivos enquanto você digita.

O que é

O winget é o instalador de programas que já vem no Windows 10 e 11. Ele baixa cada programa da fonte oficial.

Por que aprender

Git guarda versões, gh conversa com o GitHub e Node é necessário para instalar o Codex. Sem eles as partes 2 e 3 não funcionam.

Conceitos-chave

winget: instalador do Windows por linha de comando. Git: programa que guarda o histórico do projeto. gh (GitHub CLI): o GitHub dentro do terminal. Node: motor que roda programas em JavaScript, como o Codex.

O que é

Escolha um, ou os dois. Na primeira vez que abrir, o agente pede para entrar: use a sua assinatura (Claude Pro ou Max, ChatGPT Plus ou Pro).

Por que aprender

O agente é quem trabalha por você dentro da pasta: lê, cria e altera arquivos com a sua autorização.

Conceitos-chave

Agente: uma IA que executa tarefas no seu computador, não só conversa. Claude Code: o agente da Anthropic. Codex: o agente da OpenAI. Assinatura: o login da sua conta, sem chave de API.

O que é

Entre na pasta e chame o agente (claude ou codex). Ele só enxerga a pasta onde você está. O AGENTS.md guarda as regras do projeto para as próximas conversas.

Por que aprender

Aqui o ciclo fecha: você pede, o agente cria, e você confere no dir, no Explorador e no navegador.

Conceitos-chave

index.html: a página principal de um site. AGENTS.md: arquivo de instruções que o agente lê ao abrir a pasta. start: abre um arquivo com o programa padrão do Windows.
