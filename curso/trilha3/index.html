MÓDULO 3.1

VPS: o mesmo, num servidor

Entrar numa VPS Ubuntu com a sua chave, navegar com os mesmos comandos e trazer o projeto do GitHub para lá.

0%0 de 0

O que é

Escolha um provedor e o sistema Ubuntu. Na criação, ele pede uma chave SSH: cole a linha que este comando mostra. Anote o IP que o provedor informar.

Por que aprender

Com a chave cadastrada você entra sem senha, e ninguém sem a sua chave privada consegue entrar.

Conceitos-chave

VPS: um computador Linux alugado, ligado 24 horas. Ubuntu: a versão de Linux mais usada em servidores. IP: o endereço numérico do servidor. type: mostra o conteúdo de um arquivo no cmd.

O que é

Troque IP-DA-VPS pelo número do provedor. Na primeira vez ele pergunta se confia no servidor: responda yes. Para sair, digite exit.

Por que aprender

É a mesma janela de sempre, só que conectada a outra máquina. Tudo que você digitar agora acontece na VPS.

Conceitos-chave

ssh: abre uma conexão segura com outro computador. root: o administrador do Linux. ~: a pasta pessoal do usuário na VPS. exit: fecha a conexão e volta ao Windows.

O que é

Na VPS: dir vira ls, cls vira clear, type vira cat, %USERPROFILE% vira ~ e a barra é / em vez de \. cd, cd .. e mkdir são iguais. Não há Explorador: o ls faz esse papel.

Por que aprender

É por isso que o curso começa no Windows: quem entende pastas lá navega na VPS em minutos.

Conceitos-chave

ls: lista a pasta. pwd: mostra onde você está. mkdir -p: cria a pasta e não reclama se ela já existe. Linux diferencia maiúsculas: Projetos e projetos são pastas diferentes.

O que é

apt instala o Git no Ubuntu. git clone copia o repositório inteiro, com o histórico, para a pasta atual.

Por que aprender

O GitHub é a ponte: o mesmo projeto vive no Windows e na VPS, e as versões passam de um lado para o outro.

Conceitos-chave

apt: o instalador do Ubuntu (parecido com o winget). git clone: baixa um repositório pela primeira vez. && : roda o segundo comando só se o primeiro deu certo.

O que é

O comando de instalação para Linux é o da documentação oficial. No primeiro uso o agente mostra um endereço: abra no navegador do seu computador e entre com a assinatura.

Por que aprender

Com o agente na VPS, o trabalho pode continuar no servidor, mesmo com o seu computador desligado.

Conceitos-chave

install.sh: o instalador para Linux e Mac. | bash: entrega o instalador baixado para o terminal executar. Login sem tela: o agente mostra um link e um código para você autorizar de outro aparelho.

O que é

Mudou algo no Windows e deu push? Na VPS, git pull traz a mudança. Para voltar ao Windows, exit.

Por que aprender

É a rotina entre as duas máquinas: push de um lado, pull do outro, sempre pelo GitHub.

Conceitos-chave

git pull: traz as versões novas do GitHub. exit: encerra a conexão SSH. Voltar: ssh root@IP-DA-VPS e cd ~/projetos/meu-site.
