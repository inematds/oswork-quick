# OSWork Quick — organize seu ambiente de IA, direto ao ponto

A versão curta e visual do OSWork. Sete aulas de cerca de dez minutos: os mesmos assuntos
da edição completa, com o desenho explicando e o texto só amarrando.

**Você sai com:** pastas por frente de trabalho, uma ficha de orientação, um molde de
pedido reutilizável e uma rotina de conferência.

**Não tem:** programação, tela de comandos, instalação de nada.

Abra `landing.html` ou vá direto para `curso.html#trilha`. Funciona offline, guarda o seu
progresso no navegador.

Quer a versão com práticas longas? É o repositório `oswork-v5`. A versão para quem encara
terminal e linha de comando é o `oswork`.
