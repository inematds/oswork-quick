INEMA · OSWORK QUICK / NA PRÁTICA

Do terminal à sua página no ar, comando por comando.

Abra o terminal do Windows, crie a sua pasta de projetos, veja onde tudo fica, instale o Claude Code ou o Codex, guarde no GitHub com chave SSH e leve o projeto para uma VPS. Quem aprende a navegar no Windows navega na VPS do mesmo jeito.

NO FIM VOCÊ TEM

Um projeto seu, guardado e publicado.

  • A pasta C:\Users\SeuNome\projetos\meu-site, que você sabe achar no terminal e no Explorador.
  • Claude Code ou Codex trabalhando dentro dessa pasta.
  • O projeto no GitHub, com chave SSH, e uma página em SEU-USUARIO.github.io.
  • O mesmo projeto numa VPS, navegado com os mesmos comandos.

Os comandos vêm das documentações oficiais (Claude Code, Codex, GitHub CLI) conferidas em 07/10/2026. Telas e versões podem mudar: se algo aparecer diferente, leia a mensagem com calma antes de repetir o comando.
