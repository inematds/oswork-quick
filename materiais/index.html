1. Seu computador

Abra o terminal

cd

Crie a pasta projetos e a do primeiro projeto

cd %USERPROFILE%
mkdir projetos
cd projetos
mkdir meu-site
cd meu-site

Veja no Windows onde tudo fica

explorer .

Navegue com 6 comandos

cd ..
dir
cd meu-site
dir

Instale Git, GitHub CLI e Node (uma vez)

winget install --id Git.Git -e
winget install --id GitHub.cli -e
winget install --id OpenJS.NodeJS.LTS -e

Instale o agente: Claude Code ou Codex

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
npm install -g @openai/codex

Trabalhe dentro da pasta do projeto

cd %USERPROFILE%\projetos\meu-site
claude
dir
start index.html

2. GitHub

Diga ao Git quem é você

git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"
git config --global --list

Crie a sua chave SSH

ssh-keygen -t ed25519 -C "seu@email.com"
explorer %USERPROFILE%\.ssh

Conecte o gh à sua conta e envie a chave

gh auth login
ssh -T git@github.com

Crie o repositório e envie o projeto

cd %USERPROFILE%\projetos\meu-site
git init
git add .
git commit -m "primeira versão"
git branch -M main
gh repo create meu-site --public --source=. --push

Publique a página no GitHub Pages

gh api repos/{owner}/{repo}/pages -X POST -f "source[branch]=main" -f "source[path]=/"

A rotina de todo dia

git status
git add .
git commit -m "o que mudou"
git push

3. VPS

Contrate a VPS com a sua chave

type %USERPROFILE%\.ssh\id_ed25519.pub

Entre na VPS

ssh root@IP-DA-VPS

Mesma navegação, outros nomes

mkdir -p ~/projetos
cd ~/projetos
ls
pwd

Traga o projeto do GitHub

apt update && apt install -y git
cd ~/projetos
git clone https://github.com/SEU-USUARIO/meu-site.git
cd meu-site
ls

Instale o agente na VPS

curl -fsSL https://claude.ai/install.sh | bash
cd ~/projetos/meu-site
claude

Traga o que mudou e saia

cd ~/projetos/meu-site
git pull
ls
exit
